# clustering-gene-variants

Upute za pokretanje:
1. Instalacija potrebnih biblioteka
   ```pip install requirements.txt```
2. Instalacija emboss-a
   ```apt install emboss```
2. Pokretanje
   ```python main.py config.txt```
   Unutar ```config.txt```, potrebno je dodati argumente: reference_file, fragments_file, gapopen, gapextend, fragment_length
